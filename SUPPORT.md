# Support

Use GitHub issues for bug reports, reproducible crashes, packaging problems, and feature requests.

The tracker is busy because it doubles as the project's own work queue, and issues with a bracketed code in the title are internal audit items. Yours will not get lost among them.

Before opening an issue, please include:

- EVB Viewer version or commit SHA.
- Operating system and architecture.
- Whether the issue happens in the desktop app, browser workspace, or landing site.
- A small sample document when the problem depends on file content and the file can be shared publicly.
- Logs, screenshots, or recordings when they make the behavior easier to understand.

Do not attach private documents, credentials, certificates, or signing material to public issues.
