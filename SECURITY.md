# Security Policy

## Supported Versions

Security fixes are handled on the latest `main` branch and the latest published release line.

## Reporting A Vulnerability

Please do not publish exploit details in a public issue. Private vulnerability reporting is enabled on this repository: open a report from the [Security tab](https://github.com/evb0110/evb-viewer/security/advisories/new) and it stays private until a fix is published.

Include:

- A concise description of the issue and affected surface.
- Steps to reproduce or a proof of concept.
- Affected versions, platforms, and file types.
- Any practical mitigation you already know.

Non-sensitive bugs, crashes, and feature requests can use normal GitHub issues.
